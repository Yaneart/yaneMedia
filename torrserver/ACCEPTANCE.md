# Home: матрица проверки торрент-просмотра

Матрица относится к сохранённой домашней реализации, не к будущему помощнику.
Она описывает текущее требуемое поведение.

## Сценарии

| Сценарий                                  | Ожидаемый результат                                                                                |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 1440p / 4K, совместимые H.264/HEVC        | Исходное разрешение сохраняется; video mode copy, без принудительного 720p/1080p                   |
| Клиент не поддерживает исходное 1440p/4K  | Понятный отказ; автоматическое server video transcode не запускается                               |
| HDR при поддержке кодека                  | Передача исходного видео; без HDR→SDR                                                              |
| Неподдержанный звук при совместимом видео | Преобразуется только звук, размер видеокадра сохраняется                                           |
| Выбор audio                               | Фактически меняется дорожка; сохраняются позиция и последний play/pause intent                     |
| Text/ASS subtitles, fonts, sidecars       | Корректные cues после seek/audio switch; работают Off, оформление и delay                          |
| Запуск и длинный просмотр                 | Первый кадр до полной загрузки; воспроизведение продолжается за границами подготовленных сегментов |
| Seek и пауза                              | Подтверждённое абсолютное время сохраняется; pending target не записывается как просмотр           |
| Возврат, refresh, WatchDock               | Восстанавливаются серия/позиция/настройки; вне media page нет второго живого video                 |
| Другая учётная запись                     | Нет доступа к чужой session и private progress                                                     |
| Close/logout, отмена и ошибки             | Ненужные workers/ресурсы освобождаются, старый ответ не запускает прежнюю source                   |
| Лимит ресурсов, нет peers, обрыв сети     | Понятная ошибка или ограниченное восстановление, без бесконечного роста кэша                       |
| Home → Public → Home                      | Public выключает server torrent; данные и возможность домашнего просмотра сохраняются              |

## Что подтверждено, а что требует устройства

В проекте есть regression tests согласования 1440p/4K и browser capabilities,
а также opt-in FFmpeg integration fixtures для original UHD/HDR и audio conversion.
Это реализованная поддержка; отсутствие нового полного прогона не означает запрет 4K.

Проверка HDR metadata не доказывает визуальный HDR на конкретном экране. Safari/iOS,
физические устройства и производительность T480 принимаются отдельно по фактическим
результатам. Эмуляция ширины не доказывает аппаратный decoder или native touch.

## Сфокусированные команды

Из корня проекта, unit-проверки без запуска новой раздачи:

```powershell
# Папка: yaneMedia/ (корень проекта)
docker compose exec -T backend npm test -- --runInBand --runTestsByPath test/torrent/torrent-client-capabilities.spec.ts test/torrent/torrent-media-policy.spec.ts
```

Из frontend:

```powershell
# Папка: yaneMedia/frontend
bun test ./test/torrentClientCapabilities.test.ts
```

Длительные FFmpeg/real-engine fixtures запускаются отдельно по
[test guide](../backend/test/torrent/README.md), не автоматически при правке документов.
Для browser acceptance проверять реальные decoded video/audio и captions, а не только
HTTP 200, readiness или наличие пункта в меню. Непроверенный сценарий не отмечать пройденным.
