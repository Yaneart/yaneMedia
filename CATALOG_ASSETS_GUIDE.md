# Обновление каталога

Все команды выполняйте из корня проекта `yaneMedia`, где лежит `compose.yaml`.
Откройте терминал в этой папке скачанного или склонированного репозитория.

Изображения загружаются только из двух источников:

- фильмы и сериалы — TMDB (`image.tmdb.org`);
- аниме — Shikimori (`shikimori.io`).

Ручных `artworkOverrides` и резервных источников нет. Сетевые запросы повторяются при временной
ошибке, но если TMDB или Shikimori не отдали обязательное изображение, пересборка завершается ошибкой.

Перед сохранением все изображения нормализуются в WebP: постеры ограничены размером `640×960`,
бэкдропы — `3840×2160`; маленькие исходники не увеличиваются. Постерный профиль обычных media cards
не меняется. После изменения профиля изображений нужно использовать полную пересборку, чтобы заменить
уже сохранённые assets и получить новое разрешение hero banner.

## Обычное обновление подборок

Измени manifest и увеличь его `version`:

`backend/src/media/catalog/editorial-catalog.manifest.json`

Затем:

```powershell
# Папка: yaneMedia/ (корень проекта)
docker compose up --build -d backend
docker compose exec -T backend npm run catalog:sync
```

## Полная очистка и загрузка одной командой

```powershell
# Папка: yaneMedia/ (корень проекта)
docker compose exec -T backend npm run catalog:rebuild
```

Команда удаляет все ревизии каталога и assets из БД, удаляет локальные poster/backdrop и сразу
создаёт каталог заново. Если загрузка завершится ошибкой, каталог останется пустым до следующего
успешного запуска этой же команды.
